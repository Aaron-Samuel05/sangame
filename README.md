# San Andreas Browser

A browser-based game shell designed for a WebAssembly/WebGL San Andreas runtime.

## Current stage

This repository contains the frontend runtime shell:
- React + Vite
- Fullscreen game canvas
- Loading screen
- Responsive layout
- Runtime placeholder
- Ready for WASM/WebGL engine integration

## Legal / asset model

This project does not include or redistribute Rockstar Games' proprietary GTA San Andreas executable, game assets, audio, textures, models, or other copyrighted game data.

The intended integration is an engine/reimplementation that can load game data from a copy the player is legally entitled to use.

## Development

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
